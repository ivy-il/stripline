# STRIPLINE – אתר Next.js + וורדפרס Headless

אתר תדמית וקטלוג דיגיטלי ל-STRIPLINE (פתרונות אוויר אדריכליים), בנוי לפי עיצוב ה-PDF:
עמוד הבית, עמוד מוצר, התנהגות הכפתורים (שרטוט טכני / הוראות התקנה) ודף מוצר מלא להורדה כ-PDF.

```
stripline/
├─ site/                      # אתר Next.js 16 (App Router, TypeScript, Tailwind v4)
├─ wordpress-plugin/
│  └─ stripline-headless/     # תוסף וורדפרס: מוצרים, משפחות, פרויקטים, טקסטים, REST API, רענון אוטומטי
├─ tools/extract_catalog.py   # חילוץ המוצרים, התמונות וה-PDF מהקטלוג המקורי (הרצה חד-פעמית)
└─ striplineAppx.pdf          # ה-PDF המקורי (עיצוב + קטלוג Ram Air Flow)
```

## מה יש באתר

| נתיב | תיאור |
|---|---|
| `/` | עמוד הבית לפי תמונת הייחוס: הירו, 4 שערי כניסה וספר מצולם עם תוכן חי הממופה לדפים קמורים, דפדוף פעיל וקישורים למוצרים |
| `/catalog` | **הספר הדיגיטלי** – פליפ-בוק עם דפדוף מימין לשמאל. הדפים נבנים אוטומטית מהמוצרים והמשפחות שבוורדפרס (כריכה, פתיח, תוכן עניינים, דף לכל משפחה, דף לכל מוצר). לחיצה על מוצר בספר פותחת את עמוד המוצר |
| `/products` | כל המוצרים עם חיפוש (שם / מק״ט) וסינון לפי משפחה |
| `/products/[slug]` | עמוד מוצר לפי העיצוב: הירו + כרטיס תכונות + "הורדת דף מוצר PDF", כרטיס מפרט (תיאור, מידות, אביזרים, חומרים וגימור, שימוש), כפתורי **שרטוט טכני** ו**הוראות התקנה** שפותחים חלונות (מודאלים) עם הורדת DWG / PDF, מידות זמינות, מוצרים קשורים |
| `/products/[slug]/sheet` | דף מוצר מלא בפורמט A4 ממותג STRIPLINE. `?download=1` מוריד אותו כ-PDF אוטומטית |
| `/solutions` | פתרונות – משפחות המוצרים |
| `/projects`, `/projects/[slug]` | פרויקטים נבחרים |
| `/professional` | המרחב המקצועי: טבלת הורדות לכל מוצר (דף מוצר, דף טכני מהקטלוג, DWG) + הקטלוג הטכני המלא |
| `/about`, `/contact` | אודות וטופס יצירת קשר (נשלח לוורדפרס → מייל + נשמר כ"פנייה") |
| `/privacy`, `/accessibility`, `/terms` | עמודים משפטיים |

הנתונים ההתחלתיים (57 מוצרים ב-11 משפחות) חולצו מהקטלוג: תמונת מוצר, תיאור/מאפיינים/אביזרים/חומרים באנגלית, שם ותיאור קצר בעברית, ודף הקטלוג הטכני המקורי של כל מוצר (`site/public/pdf/original/*.pdf`).
מוצר EILAT מולא במלואו בעברית כדוגמה לפי ה-PDF.

## הרצה מקומית

```bash
cd site
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
```

בלי הגדרת וורדפרס האתר רץ מנתוני ה-seed שב-`site/src/data/*.json`.

**פריסה (Vercel):** הפרויקט ב-Vercel מחובר למאגר `ivy-il/stripline` עם Root Directory = `site`. כל push ל-`main` נפרס לייצור (`stripline.co.il`), וכל branch אחר מקבל כתובת Preview. משתני הסביבה (`WP_API_URL`, `REVALIDATE_SECRET`) מוגדרים ב-Vercel, לא במאגר.

פריסה לאחסון משותף (DirectAdmin / cPanel, בלי קונטיינרים): ראו [DEPLOY-DIRECTADMIN.md](DEPLOY-DIRECTADMIN.md).
`npm run pack:static` מייצר HTML סטטי לאחסון PHP רגיל, ו-`npm run pack:hosting` אורז אפליקציית Node.

## חיבור לוורדפרס (כדי לערוך טקסטים, מוצרים ופרויקטים)

1. **התקנת התוסף** – העלו את התיקייה `wordpress-plugin/stripline-headless` ל-`wp-content/plugins/` והפעילו את "STRIPLINE Headless CMS".
   בתפריט יופיעו: *מוצרים STRIPLINE*, *משפחות מוצרים*, *פרויקטים*, *פניות מהאתר*, ובהגדרות: *STRIPLINE*.
2. **ייבוא הקטלוג** – הגדרות ← STRIPLINE ← לשונית *ייבוא קטלוג* ← "ייבוא הקטלוג". כל 57 המוצרים, המשפחות ו-3 פרויקטים לדוגמה ייווצרו מוכנים לעריכה.
   (בשדה "כתובת בסיס לקבצים" מזינים את כתובת אתר ה-Next.js, כי תמונות המוצרים וה-PDF נמצאים שם. אפשר לסמן "להעתיק תמונות לספריית המדיה".)
3. **טקסטים של האתר** – לשונית *טקסטים*: כותרת ההירו, שערי הכניסה, טקסטי הקטלוג, אודות, כתובת, מייל, טלפון וכו'.
4. **חיבור** – לשונית *חיבור ל-Next.js*: כתובת האתר + מפתח סודי. אחרי כל שמירה בוורדפרס האתר מתרענן מיד (on-demand ISR).
5. **בצד Next.js** – צרו `site/.env.local` (ראו `site/.env.example`):

   ```
   WP_API_URL=https://cms.stripline.co.il/wp-json/stripline/v1
   REVALIDATE_SECRET=<אותו מפתח סודי כמו בוורדפרס>
   ```

   ופרסו מחדש (Vercel / Node). אם וורדפרס לא זמין, האתר ממשיך לעבוד עם הנתונים האחרונים / ה-seed.

### שדות המוצר בוורדפרס

מק״ט, שם באנגלית/עברית, כותרת משנה, תיאור קצר/מלא, 5 נקודות בולטות, מידות, אביזרים, חומרים וגימור, שימוש, אורכים/גבהים זמינים, הוראות התקנה (כותרת + שורות עם `- `), תמונת מוצר, תמונת אווירה, שרטוט טכני (תמונה), קובץ DWG, דף קטלוג PDF, עמודי קטלוג, "להציג בעמוד הבית", ושדות אנגלית מהקטלוג. המשפחה נבחרת בטקסונומיה "משפחות מוצרים".

הוספת מוצר חדש = "מוצר חדש" בוורדפרס ← הוא מופיע אוטומטית ברשימה, בספר הדיגיטלי, במרחב המקצועי ובעמוד המוצר שלו.

### REST API (מה שהאתר קורא)

`/wp-json/stripline/v1/settings` · `/families` · `/products` · `/products/{slug}` · `/projects` · `POST /contact`

## חילוץ מחדש מהקטלוג (אופציונלי)

```bash
pip install pymupdf pillow
python tools/extract_catalog.py
```

מייצר מחדש את `site/src/data/products.json`, `families.json`, את תמונות המוצרים ואת קבצי ה-PDF לכל מוצר.

## מה נשאר להשלים עם הלקוח

- תמונות אווירה אמיתיות (הירו, פרויקטים, מוצרים) – כרגע משמשות תמונות מה-PDF של העיצוב כממלאי מקום.
- קבצי DWG לכל מוצר (השדה קיים; עד שיועלו הכפתור מוצג כ"בקרוב").
- תרגום מלא לעברית של תיאורי המוצרים (יש שם ותיאור קצר בעברית לכולם; המפרט המלא באנגלית מהקטלוג).
- טלפון אמיתי בהגדרות.



## מיפוי תוכן על הספר בעמוד הבית

`RealisticBook.tsx` משלב את תמונת הספר הקודמת `catalog-book-blank.webp` עם דפים תלת־ממדיים ב-Three.js. הכריכה, השדרה, עובי הדפים והצללים נשמרים מהצילום. התוכן מנתוני הקטלוג נכתב עם פונט האתר על טקסטורות נפרדות לכל צד; תאורת הנייר ומרקמו נדגמים מהתמונה באמצעות `book-lighting.ts`.

`site/src/lib/book-geometry.ts` יוצר עמודים המחוברים לשרשרת של 41 עצמות על פני 40 מקטעים. `book-photo-geometry.ts` מכייל את קודקודי הדף באמצעות ההופכי של מטריצות השלד, כדי שקצות הדפים במנוחה יתאימו בדיוק לעקומות שנמדדו בתמונה ב-`book-surface.ts`. בזמן הדפדוף נשמרת תנועת השלד, ומיקומי החומר עוברים ברציפות בין הכיולים של שני צדי הספר. `book-three.ts` מנהל את הסצנה והדפדוף במשך 1.2 שניות. הקנבס מורחב מעל ומתחת לספר כדי לא לחתוך את הדף המתרומם; אזורי הקישור ב-SVG משתמשים באותם מיקומי UV ועקומות. שיטת השלד התלת־ממדי נבנתה בהשראת הדוגמה של Wawa Sensei: https://wawasensei.dev/tuto/3d-book-slider-landing-page-threejs-and-react.

כל משפחה מחולקת לכפולות של עד שישה מוצרים. דפדוף קדימה בעברית מעביר את הדף משמאל לימין; חץ שמאלה במקלדת מקדם כפולה, חץ ימינה מחזיר, והחלקת אצבע ימינה מקדמת. המימוש מכבד העדפה לתנועה מופחתת ומחזיק טקסטורות לכפולה הנוכחית ולכפולות הסמוכות בלבד, עם מטמון תמונות מוגבל. הקטלוג המלא נשאר זמין ב-`/catalog`, גם אם WebGL אינו זמין.

בדיקת התאמת הדפים לצילום, רציפות בין שני הצדדים וגבולות הדף המתרומם: מתוך `site`, הריצו `node tools/check-book-photo.mjs`. בדיקת השלד הבסיסי והכיוון העברי: `node tools/check-book-3d.mjs`.
